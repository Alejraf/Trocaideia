Desafío IQ & Trivia - App Web y Móvil
=====================================

Esta aplicación es un juego de preguntas y respuestas (Trivia / IQ) optimizado para dispositivos móviles y navegadores web. Está diseñado con un modelo de monetización publicitaria mediante pausas naturales (compatible con las políticas de Monetag al no incentivar clics forzados).

Características principales:
1. Sistema de preguntas progresivas por niveles.
2. Bloques de 3 preguntas con pausa publicitaria integrada al final de cada bloque.
3. Barra de energía y sistema de puntos canjeables por dinero real (PayPal / PIX).
4. Interfaz moderna y adaptada a dispositivos móviles con Tailwind CSS y FontAwesome.

Cómo ejecutar:
Simplemente abre el archivo 'index.html' en cualquier navegador web o súbelo a un servicio de hosting estático como GitHub Pages o Render.
